## Owner decisions, one table (2026-11-25)

Status: open for the owner. Nothing in this table is applied to the shipped build. Every number comes from the source named in its row; the source files are in /workspace/bevy/target/witness and the ledger rows in docs/PENDING_VALIDATION.md.

| # | Decision | Measured numbers (source) | Cost of not deciding | Recommendation and reason |
|---|---|---|---|---|
| 1 | Is the planet visible during the warm pass (the scripted flight that creates the pipelines before the planet is shown)? | Hidden, flight: warm pass 39.5 s and 33.9 s, 1,799 frames each not shown; reveal stall (largest frame interval from reveal) 176 ms and 122 ms (r8-flight-warm-hidden-1, -2). Hidden, ground: warm pass 36.7 s and 30.3 s; reveal stall 308 ms and 173 ms (r8-ground-warm-hidden-1, -2). Earlier hidden runs: reveal stall 671 ms and 232 ms on ground, 207 ms on flight (r6, r7). | 2 | Drop patch shadow casting (the 1,700 patch entities no longer cast shadows; terrain self-shadowing is lost) | Idle callback busy p50 20.8 ms with patch shadows, 14.2 ms without (about minus 32 percent; the spec cites minus 30 percent). Round 2 experiment, reverted; raw output not kept, not re-measured on the current tree. | The shadow pass stays in every flight; the idle callback keeps about 6.6 ms more per frame than without casting. | Do not drop it now. The reduction is idle-only: the flight, where the hitches are seen, gains nothing (14.7 against 15.8 ms). Dropping it removes terrain self-shadowing, which the parity spec requires. If idle CPU becomes a goal, measure a casting-distance cap first (not measured). |
