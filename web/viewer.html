Launching real Bevy WebGPU WASM…

The canonical viewer now loads web/wasm/, where wasm-bindgen glue mounts a Bevy WebGPU canvas. If WebGPU is unavailable, that page keeps the generated status report as a diagnostic fallback.

If you are not redirected, open ./wasm/ or run:
scripts/build-wasm.sh
